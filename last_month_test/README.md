

# 📘  월말평가 총정리 (원본 문제 기준)

## ✅ 2001. 파리 퇴치

### 문제 요약

* N×N 배열에서 M×M 크기의 파리채로 파리 최대 퇴치 수 구하기.
* 단 한 번만 내리침.

### 풀이 전략

1. **브루트포스**: 모든 시작 좌표 (i, j)에 대해 M×M 부분합 계산.
2. 최댓값 갱신.
3. **시간 복잡도**: O(N²M²) → N, M ≤ 15라 충분히 가능.

## ✅ 1959. 두 개의 숫자열

### 문제 요약

* 길이가 다른 두 수열 A(N), B(M).
* 짧은 쪽을 긴 쪽 위에서 슬라이딩 → 곱의 합의 최댓값 구하기.

### 풀이 전략

1. 항상 **짧은 배열**을 긴 배열 위에서 이동.
2. 각 위치마다 원소끼리 곱한 합 계산.
3. 최댓값 갱신.
4. **시간 복잡도**: O(NM) (N, M ≤ 20 → 매우 작음).

## ✅ 태양열 에너지

### 문제 요약

* N×N 태양광 패널 + M×M 렌즈.
* 렌즈를 올리면, 그 영역의 **(패널 값 + 렌즈 값)** 합이 하나의 칸이 됨.
* 새로운 패널 크기 = (N-M+1) × (N-M+1).

### 풀이 전략

1. 렌즈 전체 합(`lens_sum`)을 미리 계산.
2. 각 위치 (i, j)에 대해 패널 부분합(`M×M`)을 구한다.
3. 최종 값 = 부분합 + lens_sum.
4. 반복 → 새로운 패널 생성.
5. **시간 복잡도**: O(N²M²) (N ≤ 50 정도면 누적합 이용).

   * 효율성: 2D prefix sum 사용 시 → O(N²).

## ✅ 서술형 대비 (DFS, BFS, MST, Dijkstra)

### 암기용 요약

* **DFS (깊이우선탐색)**

  * 스택/재귀, 깊게 탐색 → 끝까지 갔다가 돌아옴.
  * **활용**: 백트래킹, 경로 탐색.

* **BFS (너비우선탐색)**

  * 큐, 가까운 곳부터 탐색.
  * **활용**: 최단 거리 문제.

* **MST (최소 신장 트리)**

  * 모든 정점을 최소 비용으로 연결.
  * Prim(정점 중심), Kruskal(간선 중심).

* **Dijkstra (다익스트라)**

  * 시작점 → 모든 정점 최단 거리.
  * 우선순위 큐, 음수 가중치 불가.
  * **활용**: 네비게이션.

# ✅ 시험 직전 암기 포인트

- **파리 퇴치**: 모든 M×M 합 → 최댓값. (브루트포스 OK)
- **두 개의 숫자열**: 짧은 쪽 슬라이딩 → 곱합 최대.
- **태양열 에너지**: 부분합 + 렌즈합 → 새로운 판넬. (누적합 쓰면 빠름)
- DFS: 깊게 탐색, 스택/재귀, 백트래킹
- BFS: 넓게 탐색, 큐, 최단거리
- MST: 네트워크 최소 비용 연결 (Prim=점, Kruskal=선)
- Dijkstra: 최단경로(네비), 음수X
